# Start Here

Welcome to Terrarium! These examples are yours to run, read and change.
Tap a link to open one, then tap **Run** (▶). Change a number, a color
or a word and run it again: that's how to learn what each line does.

## First steps

- [Hello](Hello.py): `print()` and `input()`.
- [Guess the Number](Guess%20the%20Number.py): a loop, `if` and random numbers.
- [Countdown](Countdown.py): `time.sleep`, and stopping a program with ■.
- [Files](Files.py): writing and reading a file next to the program.
- [Turtle](Turtle.py): drawing with a turtle; [Turtle Fractals](Turtle%20Fractals.py) grows
  ferns and snowflakes from a few rules, and [Catch the Turtle](Catch%20the%20Turtle.py) is a game.

## Apps

Programs that `import ui` open full screen as native iOS apps
([the ui module](docs:3.14/terrarium/ui.html)).

- [Counter App](Counter%20App.py): the smallest app, with a signal.
- [Settings](Settings.py): every kind of input. [Navigation](Navigation.py),
  [Tabs](Tabs.py) and [Async Data](Async%20Data.py) show screens, tabs and loading.
- [Todo App](Todo%20App.py): a complete to-do app, saved in SQLite.
- [Journal](Journal.py): a diary with moods, SQL queries and a passcode in the Keychain.
- [Weather](Weather.py): the forecast for where you are, from a web service.
- [Pomodoro](Pomodoro.py): a focus timer with notifications.

## Games, drawing and sound

- [Brick Breaker](Brick%20Breaker.py): a game with a game loop; steer by tilting the phone.
- [Bounce](Bounce.py) and [Paint](Paint.py): the canvas, animated and with your finger.
- [Game of Life](Game%20of%20Life.py): cells that live and die, computed with numpy.
- [Mandelbrot](Mandelbrot.py): tap to zoom into a fractal, on all CPU cores.
- [Piano](Piano.py) and [Drum Machine](Drum%20Machine.py): sounds made from sine
  waves and noise.

## Data and science

- [Notebook](Notebook.ipynb): what notebooks do, cell by cell; [Cells](Cells.py)
  does the same in a plain `.py` file.
- [Earthquakes](Earthquakes.ipynb): live data with pandas and maps with matplotlib.
- [Plot](Plot.py): a chart in the console.
- [Draw a Digit](Draw%20a%20Digit.py): machine learning that reads your handwriting.
- [Processes](Processes.py): several Pythons working at once.

## Your iPhone

[The device modules](docs:3.14/terrarium/index.html) use the phone itself.

- [Device Tour](Device%20Tour.py): dialogs, speech, the clipboard, sounds.
- [Clipboard Tools](Clipboard%20Tools.py): change copied text; nice on the Home Screen.
- [Photo Booth](Photo%20Booth.py): the camera and photo filters.
- [Voice Memos](Voice%20Memos.py): record, play back and transcribe.
- [Level](Level.py): the motion sensors and a map.
- [Birthdays](Birthdays.py): contacts, reminders and notifications.

## Learn the tools

- [Debug Me](Debug%20Me.py): a bug to find with breakpoints and stepping.
- [Types](Types.py): mistakes the editor finds before you run.
- [Async](Async.py): many web requests at once with `asyncio`.
- [Web Requests](Web%20Requests.py): talking to a web API.
- [Dependencies](Dependencies.py): using packages from PyPI.
- [Adventure](Adventure/README.md): a text adventure in several files that
  import each other.

Stuck? The ✨ button asks the coding agent, and the ⋯ menu has the
[Python documentation](docs:3.14/index.html).
