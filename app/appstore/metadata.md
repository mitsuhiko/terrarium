## Description (4000)

Terrarium is a Python IDE for iPhone and iPad. Python 3.14 runs on your device, with no server and no account. Write a script, run it and see the output, a plot or an app of your own.

EDIT
• A code editor with Python highlighting, completions and an extra row of keys for brackets, quotes and indentation
• Mistakes are underlined as you type (ruff and ty), with quick fixes and code formatting
• Tabs, split view on iPad, go to definition, an outline and find in folder
• Full support for hardware keyboards and their shortcuts

RUN
• A console with input(), a >>> prompt and plots right in the output
• numpy, pandas, matplotlib and hundreds more packages. Declare dependencies the way uv does, and they install when the program runs
• HTTP with requests, urllib and httpx
• multiprocessing and subprocess
• Turtle graphics, drawn and animated in the console

DEBUG
• Breakpoints, stepping, the stack and its variables
• Tracebacks that open the failing line and leave out the noise

NOTEBOOKS
• Open and run Jupyter notebooks (.ipynb), or # %% cells in a .py file
• Rich output: tables, Markdown, HTML, images and figures

BUILD APPS
• The ui module makes native iPhone and iPad apps in a few lines of Python: lists, forms, navigation, sheets and a canvas
• Device modules for the clipboard, dialogs, photos, the camera, location, motion, sound, speech, contacts, reminders and notifications
• Run a program from the Home Screen with a Shortcut

LEARN
• The complete Python documentation for 3.14 and 3.15, searchable and offline
• help() opens the documentation
• Examples to start from

CODING AGENT (OPTIONAL)
• Ask an agent to explain an error, write a program or change your files. It reads your project, runs Python and checks its own work
• Bring your own model provider: sign in with a subscription you already have, or add an API key. Nothing is sent until you allow it

FILES
• Your projects are in the Files app. Link folders from iCloud Drive or other apps and work on them in place
• Trash, favorites, templates, Quick Look and sharing

Terrarium collects no data. Your code stays on your device.
